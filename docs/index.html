How the investigation works

These specialist functions approach the same material from different directions — combined, added, or retired as the work needs, not a fixed cast. Git history makes every change reviewable. Read the full department charter ↗

01

Statistician

Glyph/compound-sign entropy, frequency, sequence structure, and reverse-boustrophedon effects.

02

Linguist

Tests whether observed structure behaves like an encoded natural language.

03

Cryptanalyst

Tests full-writing-system vs. mnemonic/notation vs. post-contact hypotheses.

04

Historian

Checks provenance, oral tradition, sources, and previous claimed decipherments.

05

Skeptic

Tries to break every leading idea — including "this is not a full writing system."
